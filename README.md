# Wave — AI-Powered Planning App

Wave is a personal software project built with **SwiftUI** that helps users turn their goals, strengths, weaknesses, available time, and deadlines into personalized daily plans.

The project explores how AI can support planning through a simple, user-friendly mobile interface.

## ✨ Features

- **Personalized planning:** Generates daily plans based on the user's goals, strengths, and constraints.
- **AI-assisted interviews:** Collects relevant information to make plans more personalized.
- **Safety checks:** Helps identify unsuitable goals and redirect users toward safer alternatives.
- **Task tracking:** Allows users to track completed tasks.
- **Local persistence:** Preserves saved plans and progress between app sessions.

## 🛠️ Built With

- **Swift**
- **SwiftUI**
- **Supabase Edge Functions**
- **Google Gemini API**

## 🏗️ Architecture

Wave uses a SwiftUI frontend connected to server-side Supabase Edge Functions for AI-powered features.

The backend handles AI requests and related safety checks, while the app provides the user interface and task-management experience.

API credentials are stored as server-side secrets rather than embedded in the app's source code.

## 🎯 Project Goals

Wave was built to develop practical skills in:

- iOS application development
- AI API integration
- Backend development and serverless functions
- User-centered software design
- Data persistence and application state management
